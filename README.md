# Security Notes

هذا المشروع هو موقع ثابت يتم نشره عبر GitHub Pages ويعرض مقالات وتقارير أمنية.

## هيكل الموقع

- `index.html` : الصفحة الرئيسية
- `styles.css` : التنسيق العام
- `articles/first-article.html` : أول مقال
- `reports/security-report-01.html` : أول تقرير

## النشر

## ملاحظات

- الموقع يعمل كـ static website بدون أي backend.
- يمكن إضافة مقالات جديدة بسهولة عبر إنشاء ملفات HTML جديدة وربطها بالصفحة الرئيسية.
- لاحقًا يمكن ربط دومين مخصص مثل `securitynotes.dev` عبر GitHub Pages أو Cloudflare.
